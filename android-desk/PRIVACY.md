# Tetherlume — Privacy / Datenschutz

## English
The launcher is designed for local USB use. It contains no telemetry, account system, automatic update requests, crash-report uploads or cloud storage. Audio and automatic clipboard synchronization are disabled. Manual clipboard operations remain possible. Screen recordings are created only at a user-selected path; avoid cloud-synced folders if local-only storage is required. Diagnostic output is discarded by the launcher. Windows and ADB can retain local settings and authorization keys. The screen-off preference is stored in the current user's registry. The Help button opens the project website only when clicked. The planned offline installer includes scrcpy; downloading the installer itself requires access to the hosting provider. Windows, Android and bundled components have independent behavior and privacy policies. Use only authorized devices and revoke USB debugging authorizations when finished. No claim of certified GDPR compliance or independently verified zero network traffic is made.

## Deutsch
Der Launcher ist für lokale USB-Nutzung ausgelegt. Er enthält keine Telemetrie, Nutzerkonten, automatischen Updateabfragen, Uploads von Fehlerberichten oder Cloud-Speicherung. Audio und automatische Zwischenablagesynchronisierung sind deaktiviert; manuelle Zwischenablagefunktionen bleiben möglich. Aufnahmen entstehen nur auf Wunsch am gewählten Pfad. Für ausschließlich lokale Speicherung keine Cloud-Ordner verwenden. Technische Ausgaben werden verworfen. Windows und ADB können lokale Einstellungen und Autorisierungsschlüssel speichern. Die Einstellung zur Displayabschaltung steht in der Benutzerregistrierung. Die Hilfe öffnet die Projektwebsite nur auf Klick. Das geplante Offline-Setup enthält scrcpy; der Download selbst erfolgt über den Hostinganbieter. Windows, Android und Drittkomponenten haben eigenes Verhalten und Datenschutzbedingungen. Nur autorisierte Geräte verwenden, USB-Debugging anschließend deaktivieren und Freigaben widerrufen. Keine Zertifizierung der DSGVO-Konformität oder unabhängig bestätigte Netzwerkfreiheit.

## Release gate
Verify upstream archive SHA-256, license notices and corresponding source obligations before distribution. Run installation/startup/uninstall tests, Defender scan where available, and manual USB/MP4 and network observation on a real Windows system. No public binary release until manual review. See https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement for hosting privacy.
