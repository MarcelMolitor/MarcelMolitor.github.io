Get connected in three steps

The privacy-hardened version is under development. Use only verified releases.

  1. Install Tetherlume. The planned offline setup includes scrcpy from Genymobile. Release approval is pending.
  2. Enable USB debugging. Tap Build number seven times in About phone, then enable USB debugging in Developer options. Labels vary by device.
  3. Connect your phone. Use a USB data cable, unlock your phone, open Tetherlume and approve the debugging prompt.

Record your screen

Choose “Record MP4”, select a destination and use your phone in the mirrored window. Close the mirrored window to finalize the recording.

Compatibility

Windows 11 x64 and a compatible Android device connected by USB. Individual features depend on the device and operating system. Check the USB data cable, debugging authorization and Windows USB driver if connection fails.

Privacy and local processing

The new source code contains no built-in telemetry, automatic crash reporting or cloud uploads. Audio forwarding and automatic clipboard synchronization are disabled. Recordings are created only on request in the selected location. Diagnostic output is not saved to log files. These changes are not yet available in a verified executable.

USB debugging grants the connected computer extensive access. Use only devices you own or are authorized to control; disable debugging and revoke authorizations when appropriate. Recordings may contain confidential information. Windows, Android, scrcpy and synchronized folders have their own settings and privacy terms.

GitHub Pages logs IP addresses for security. GitHub downloads and PayPal links involve processing by those providers; the planned offline installer bundles scrcpy.
