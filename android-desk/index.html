Get connected in three steps

Download Tetherlume only from this page or the official GitHub releases page. The SHA-256 checksum helps you verify the file.

  1. Install Tetherlume. Download the setup and run it. It includes scrcpy from Genymobile. If Windows SmartScreen warns you, verify the source, signature and checksum before proceeding.
  2. Enable USB debugging. Tap Build number seven times in About phone, then enable USB debugging in Developer options. Labels vary by device.
  3. Connect your phone. Use a USB data cable, unlock your phone, open Tetherlume and approve the debugging prompt.

Record your screen

Choose “Record MP4”, select a destination and use your phone in the mirrored window. Close the mirrored window to finalize the recording.

Compatibility

Windows 10 or 11 (64-bit) and a compatible Android device connected by USB. Individual features depend on the device and operating system. Check the USB data cable, debugging authorization and Windows USB driver if connection fails.

Privacy and local processing

The new source code contains no built-in telemetry, automatic crash reporting or cloud uploads. Audio forwarding and automatic clipboard synchronization are disabled. Recordings are created only on request in the selected location. Diagnostic output is not saved to log files. These changes are not yet available in a verified executable.

USB debugging grants the connected computer extensive access. Use only devices you own or are authorized to control; disable debugging and revoke authorizations when appropriate. Recordings may contain confidential information. Windows, Android, scrcpy and synchronized folders have their own settings and privacy terms.

GitHub Pages logs IP addresses for security. GitHub downloads and PayPal links involve processing by those providers; the Windows setup bundles scrcpy. GitHub privacy statement · PayPal privacy statement. Your language choice is stored locally in the browser after selection. These notes are not a complete legal privacy statement.

Android screen mirroring: common questions

Why is my Android phone not detected on Windows?

Use a USB data cable rather than a charging-only cable. Unlock the phone, enable USB debugging and accept the authorization prompt. Check the device manufacturer’s USB driver if necessary.

Can I control my phone with a mouse and keyboard?

Tetherlume uses scrcpy to mirror and control compatible Android devices. Some device settings or protected apps may restrict input or screen capture.

Do I need an account?

The Windows USB workflow does not require a Tetherlume account. Check the installation instructions and release status before downloading.
