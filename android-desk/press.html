Projektprofil

Tetherlume entwickelt eine Windows-Oberfläche zur Android-Bildschirmspiegelung und Steuerung per USB mit Maus und Tastatur sowie MP4-Aufnahmen. Ziel ist ein einfacher Einstieg in die lokale Smartphone-Steuerung.

Entwicklungsstand: Ein Windows-Setup inklusive scrcpy (Windows 10/11, 64 Bit) steht zum Download bereit; Windows SmartScreen kann bei neuen Programmen warnen. Die Web-Vorschau verweist für echte Steuerung auf externes WebADB. Eine signierte Veröffentlichung und unabhängige Kompatibilitätstests stehen noch aus.

English press information

Tetherlume is an independent open-source project developed in Germany, based on scrcpy. It aims to simplify Android screen mirroring, USB control and MP4 recording on Windows.

A Windows setup including scrcpy (Windows 10/11, 64-bit) is available for download; Windows SmartScreen may warn about new programs. The web preview relies on external WebADB for actual device control. Signed releases and independent compatibility testing are pending.
