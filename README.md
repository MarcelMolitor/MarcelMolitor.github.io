## Im Browser

- **[Tetherlume Web](https://marcelmolitor.github.io/tetherlume/web/)** (Early Access) – Android-Handy per USB live im Browser: Live-Video bis 60 FPS, Maus & Tastatur, Dateien und APKs per Drag & Drop, ohne Installation. [Demo ansehen](https://marcelmolitor.github.io/tetherlume/web/#demo)

  | Plattform | Download |
  |---|---|
  | 🌐 Web | [Im Browser starten](https://marcelmolitor.github.io/tetherlume/web/) |
  | 📲 Android | Android-App mit „Bildschirm im WLAN teilen“: [Test-APK](https://github.com/MarcelMolitor/MarcelMolitor.github.io/releases/download/tetherlume-android-latest/Tetherlume.apk) |
  | 🖥 Windows | [Windows-Setup](https://github.com/MarcelMolitor/MarcelMolitor.github.io/releases/download/tetherlume-windows-latest/Tetherlume-Setup.exe) · [Windows-Version](https://marcelmolitor.github.io/android-desk/) |

- **[EPUB-Leser](https://marcelmolitor.github.io/epub-leser/)** – EPUB-Bücher im Browser lesen; Bücher bleiben lokal, mit Themes und Lesezeichen.

## Windows-Tools

- [Photo Size Limiter](https://marcelmolitor.github.io/fotolimit/) – JPEG-Kopie unter 1 MB für Online-Formulare

- [Phone Wallpaper Fitter](https://marcelmolitor.github.io/displayfit/) – Handy-Hintergrund in 1080 × 1920
