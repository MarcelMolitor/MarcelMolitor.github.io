Was verarbeitet wird

Das freiwillige Konto verwendet Supabase Auth für E-Mail-Adresse, Benutzerkennung, Authentifizierung und Sitzungsdaten. GitHub Pages stellt die Website bereit. Die Anmeldeseite lädt die Supabase-Bibliothek von jsDelivr. Dabei können die jeweiligen Anbieter technische Verbindungsdaten verarbeiten.

Smartphone-Inhalte

Die experimentelle USB-Steuerung empfängt Bildschirmaufnahmen über WebUSB und verarbeitet diese im Browser. Der Anwendungscode sieht keinen Upload von Bildschirmaufnahmen vor. Screenshots werden nur auf Wunsch heruntergeladen. Die ADB-Bibliotheken werden von esm.sh geladen; dabei können technische Verbindungsdaten anfallen. Die Integrität und Datenschutzpraxis dieser Abhängigkeiten müssen vor dem regulären Betrieb geprüft werden.

Lokale Speicherung

ADB-Authentifizierungsschlüssel können in IndexedDB gespeichert werden. USB-Berechtigungen können in den Browsereinstellungen und Debugging-Autorisierungen am Smartphone widerrufen werden. Das bevorzugte Vorschauformat wird im lokalen Browserspeicher gespeichert und kann im Dashboard gelöscht werden. Supabase Auth speichert Sitzungsinformationen im Browser; eine Abmeldung beendet die lokale Sitzung.

Eine automatische Kontolöschung ist noch nicht verfügbar.
